# 전례일 표시 옵션 (달력 그리드) - 설계 (Design)

작성일: 2026-07-27
브랜치: `feature/일정-반복`에서 이어서(또는 별도 브랜치)

## Context
메인 달력 그리드의 각 날짜 셀에는 전례일 축약명 텍스트가 표시된다(휴대폰 `CompactDayCell`,
웹 `DayCell`). 사용자는 이 텍스트를 **얼마나 표시할지**를 설정에서 고르고 싶어 한다(정보량 조절).
현재는 `calendar.shortTitleFor(day)`가 있는 날만 표시되는데, 이 축약명은 **명명된 축일 ~25개**
(`kDefaultLiturgicalShortTitles`) + 서버(CBCK) 제공분뿐이라, **평범한 주일(연중/사순/부활/대림
제N주일, `celebration.id == 'sunday'`)과 평일은 축약명이 없어 아무것도 안 뜬다**(2026년 감사: 52개
주일 중 41개가 축약명 없음).

## 확정된 결정 (사용자 확인)
- 옵션 4가지:
  1. **모든 전례일**: 라벨이 있는 모든 날(= 명명 축일/성인일 + 모든 주일). 평범한 평일은 미표시.
  2. **대축일/축일만**: 대축일 + 성인일만.
  3. **주일에 대축일만(기본값)**: 모든 주일(주일 이름) + 대축일.
  4. **표시 안함**: 항상 숨김.
- 기본값 = **주일에 대축일만**.
- 적용 범위 = **앱 달력 그리드만**(compact + wide). 홈 위젯은 범위 밖(현행 유지).
- 색 점(개인 일정)·상단 전례색 바는 모드와 무관하게 유지. **텍스트만** 필터링.
- 주일 축약: 제목 끝의 "주일"을 떼어 표기. 연중 제18주일 → **연중 제18**, 사순 제2주일 → 사순 제2,
  부활 제3주일 → 부활 제3, 대림 제1주일 → 대림 제1. (이 정보는 DB가 아니라 엔진 계산 제목에서
  코드로 변환한다. 성가정 축일처럼 주일이지만 명명 축일이면 그 축일명을 쓴다.)

## 설계

### 1) 라벨 결정 - `lib/features/calendar/data/` (헬퍼 또는 CalendarService 메서드)
라벨 우선순위(표시하기로 결정된 날에 대해):
1. `cal.shortTitleFor(day)` (서버 CBCK 축약명 → 명명 축일 맵 ~25개). 있으면 사용.
2. 없고 `day.celebration.id == 'sunday'`이며 제목이 `^(연중|사순|부활|대림) 제\d+주일$`이면 → "주일"
   제거(예: "연중 제18").
3. 그 외 → **`day.title`(전체 제목) 폴백**. (예: "성 야고보 사도 축일" - 축약명 맵에 없는 성인 축일도
   이름이 보이도록. 셀이 좁으면 말줄임.)
- 근거: `shortTitleFor`(`calendar_service.dart:114`)는 명명 축일 ~25개만 반환하므로, 폴백이 없으면
  대다수 성인 축일이 빈칸이 된다. 와이드 셀은 이미 `shortTitle ?? day.title`(`day_cell.dart:107`)로
  폴백하므로 이 규칙과 정합. 어떤 날을 "표시할지"는 아래 필터가 결정하므로, 평일은 애초에 여기 안 온다.

### 2) 표시 필터 - 신규 `lib/features/calendar/application/liturgical_display_filter.dart`
```dart
enum LiturgicalDisplayFilter { all, feastsOnly, sundaysAndSolemnities, none }
```
`bool showsLabelFor(LiturgicalDisplayFilter f, LiturgicalDay day)`:
- `all`(모든 전례일): `day.celebration.rank != Rank.feria` (평범한 평일만 제외 = 주일·명명 축일·성인일
  모두 표시. 평일 "연중 제N주간 ○요일"은 제외).
- `feastsOnly`(대축일/축일만): `day.celebration.rank == Rank.solemnity ||
  day.celebration.kind == CelebrationKind.sanctorale`.
  (성인일 판정은 `kind == sanctorale`가 모든 연도에 안정적. `displayType`은 데이터 있는 날만 채워져
  폴백 연도에 불안정하므로 kind 사용.)
- `sundaysAndSolemnities`(기본): `day.date.weekday == DateTime.sunday ||
  day.celebration.rank == Rank.solemnity`.
- `none`: false.

그리드 표시 최종: `label != null && showsLabelFor(filter, day)`.

### 3) 설정 저장/상태 - 같은 파일 또는 `settings` 하위
- `liturgicalDisplayFilterProvider` = `NotifierProvider<LiturgicalDisplayFilterController,
  LiturgicalDisplayFilter>`. `build()`는 기본값(`sundaysAndSolemnities`) 반환 후 SharedPreferences
  에서 비동기 하이드레이트(`sharedPreferencesProvider.future`), 키 `liturgical_display_filter`.
  `set(filter)`는 상태 갱신 + prefs 저장. (event_providers의 `sharedPreferencesProvider` 재사용.)

### 4) 그리드 적용 - `month_grid.dart`
- `build`에서 `final filter = ref.watch(liturgicalDisplayFilterProvider);`
- `final shortTitle = inMonth ? _gridTitle(calendar, day, filter) : null;`
  (`_gridTitle` = 라벨 결정 + 필터 → 표시할 문자열 or null). compact/wide 셀 공통(이미 `shortTitle`
  파라미터를 둘 다 받음). null이면 텍스트 미표시(색/점 유지).

### 5) 설정 화면 UI - `settings_page.dart` + 신규 선택 페이지
- `settings_page`에 **"달력"** 섹션 추가 → `ListTile('전례일 표시', trailing: 현재 모드명)` → 탭 시
  `LiturgicalDisplaySettingsPage` push.
- 선택 페이지: 상단 **미리보기 주간 그리드**(대표 샘플 날: 평범한 주일/대축일/성인축일/기념일/평일을
  고정 데이터로 구성) + 아래 4개 `RadioListTile`. 옵션을 고르면 미리보기가 즉시 그 모드로 갱신되고,
  선택 시 `liturgicalDisplayFilterProvider.set(...)`로 저장.
- 미리보기는 실제 셀 렌더와 동일 규칙(위 라벨+필터)을 쓰는 소형 위젯. AdMob 없음(설정 화면 규칙).

## 주요 파일
- 신규: `lib/features/calendar/application/liturgical_display_filter.dart`(enum+provider+필터 함수),
  라벨 헬퍼(`liturgical_grid_title.dart` 또는 CalendarService 메서드),
  `lib/features/settings/presentation/liturgical_display_settings_page.dart`(선택+미리보기).
- 수정: `month_grid.dart`(필터 적용), `settings_page.dart`("달력" 섹션),
  (라벨 폴백 위치에 따라) `calendar_service.dart` 또는 신규 헬퍼.

## 범위 밖 (YAGNI)
- 홈 위젯 반영. 평일(연중 제N주간 ○요일) 서수 표시. 요일/색/폰트 커스터마이즈.
- 서버/백오피스의 축약명 편집(별개 기능).

## 검증 (End-to-End)
1. 단위: 라벨 폴백(연중 제18주일→"연중 제18", 사순/부활/대림, 명명 축일은 맵값, 평일 null).
2. 단위: `showsLabelFor` 4모드 × 대표 날(평범 주일/대축일/성인 축일/성인 기념일/평일) 진리표.
3. 프로바이더: 저장→새 컨테이너에서 복원, 기본값=sundaysAndSolemnities.
4. 위젯: 선택 페이지 4옵션 렌더 + 선택 시 저장 호출, 미리보기 변화.
5. `flutter analyze` 무경고, `flutter test` 통과.
