# 가톨릭 달력 업데이트 안내

이번 업데이트로 이런 점들이 달라졌어요.

## 기능이 새로 추가되었어요.

- **나만의 일정을 달력에 담을 수 있어요.** 원하는 날짜에 일정을 추가하고, 메모와 시간(또는 종일)을 함께 적어 둘 수 있어요.
- **일정 종류를 직접 만들어 쓸 수 있어요.** '본당 행사', '기도'처럼 나만의 카테고리를 색과 함께 만들어 두고, 일정을 추가할 때 골라서 등록해요.
- **반복 일정을 만들 수 있어요.** 매일 / 매주 / 매월 / 매년은 물론, '매년 부활 대축일처럼' 해마다 날짜가 바뀌는 전례 축일에 맞춰 반복되는 일정도 만들 수 있어요.
- **여러 날에 걸친 일정도 등록할 수 있어요.** 시작일과 종료일을 정해 연속되는 일정을 표시해요.
- **성인을 찾아 축일을 추가할 수 있어요.** 성인을 검색해 축일을 달력에 넣을 수 있고, 축일은 기본적으로 해마다 반복돼요(원하면 끌 수 있어요).
- **알림 시점을 직접 고를 수 있어요.** 5분 전부터 1주일 전까지 원하는 때로 알림을 맞출 수 있고, 한 일정에 알림을 최대 2개까지 둘 수 있어요. 종일 일정은 며칠 전 아침에 알려드려요.
- **홈 화면 위젯을 제공해요.** 홈 화면에서 바로 오늘의 전례와 내 일정을 볼 수 있어요(iPhone·Android 모두 지원, 위젯 크기도 고를 수 있어요).
- **달력에 전례일을 얼마나 보여줄지 고를 수 있어요.** 설정에서 '모든 전례일 / 대축일·축일만 / 주일에 대축일만 / 표시 안 함' 중에 선택해요.
- **내 일정을 백업하고 복원할 수 있어요.** iCloud나 구글 드라이브에 저장해 두면 기기를 바꾸거나 앱을 다시 설치해도 일정을 되살릴 수 있어요. 마지막 백업 후 시간이 지나면 잊지 않도록 알려드려요.
- **설정 화면이 생겼어요.** 화면의 '+' 버튼을 누르면 일정 추가, 축일 추가, 설정으로 바로 갈 수 있고, 설정에서 개인정보 처리방침과 앱 버전을 확인할 수 있어요.
- **새 버전이 나오면 앱에서 안내해 드려요.** 업데이트가 있을 때 알려드려 최신 상태로 쓰실 수 있어요.

## 기능이 개선되었어요.

- **메인 화면을 더 깔끔하게 다듬었어요.** 상단 헤더와 하단 정보 카드를 정리하고, 그 날의 전례 색을 화면 위쪽까지 자연스럽게 이어지도록 했어요.
- **상세 화면을 새롭게 단장했어요.** 전례력·내 일정·오늘의 말씀을 카드 형태로 보기 좋게 모아 보여드려요.
- **메모를 여러 줄로 적을 수 있어요.** 한 줄로만 보이던 메모가 이제 여러 줄로 늘어나 길게 적어도 편하게 볼 수 있어요.
- **짧은 알림도 제때 울리도록 개선했어요.** Android에서 '5분 전', '30분 전' 같은 짧은 알림이 절전 상태에서도 정확한 시각에 오도록 했어요.
- **알림 설정 흐름을 매끄럽게 다듬었어요.** 알림 권한이 꺼져 있으면 상황에 맞게 안내하고, 설정으로 바로 이동할 수 있게 했어요.
- **일정과 카테고리 입력이 더 편해졌어요.** 입력 화면과 키보드 동작을 정돈하고, 카테고리 추가·수정을 전체 화면에서 편하게 할 수 있도록 바꿨어요.
- **위젯을 더 안정적으로 만들었어요.** 자정이 지나면 오늘 날짜와 전례가 제때 갱신되고, 여백과 일정 표시도 보기 좋게 손봤어요.
- **삭제할 때 한 번 더 확실히 확인해요.** 실수로 지우지 않도록 삭제 확인 안내를 더 또렷하게 했어요.
- **화면이 세로로 고정돼요.** 기기를 돌려도 화면이 가로로 회전하지 않아 안정적으로 볼 수 있어요.
